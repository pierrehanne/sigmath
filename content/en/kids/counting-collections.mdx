## Count a collection

Move the objects you have already counted. When there are many, make **groups of ten**, then count the loose objects. Six groups of ten and three loose objects make:

$$60 + 3 = 63$$

<NumberGarden />

In CP, pupils count to 100. In CE1, the same method reaches 1,000; in CE2, it reaches 10,000. Only the number of groups changes.

<Callout title="Remember">
Moving or arranging objects does not change how many there are. Organising a collection only makes the quantity easier to see.
</Callout>
