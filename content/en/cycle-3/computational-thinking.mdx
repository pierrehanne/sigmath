An algorithm is an unambiguous instruction sequence that transforms a starting situation into a result.

## Sequence, input, output, repetition

In primary school, calculation programs, growing patterns, coded routes and construction programs already develop computational thinking. Year 7 explicitly names instructions, sequences, inputs, outputs and repetitions.

<AlgorithmLab />

A calculation program has an input such as 5, then applies instructions in order: add 2, multiply by 4, subtract 3. The output is $(5 + 2) \times 4 - 3 = 25$.

A loop avoids copying an instruction. “Repeat 4 times: move forward, turn right” traces a square route.
